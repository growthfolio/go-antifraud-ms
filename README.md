# Go Antifraud — estudo/protótipo

> **Projeto educacional e histórico.**
> Não é um sistema antifraude validado, não utiliza um modelo comprovado em dados
> financeiros reais e não deve ser usado para decisões sobre transações.

Este repositório foi criado para estudar Go e experimentar como regras de risco,
APIs e componentes de backend poderiam ser organizados em um protótipo relacionado
a análise de transações.

## Objetivo de aprendizado

Os principais temas explorados no código e nos exemplos são:

- APIs HTTP em Go;
- separação de responsabilidades;
- regras simples de pontuação de risco;
- persistência e cache como conceitos de arquitetura;
- logging e observabilidade;
- Docker;
- estudo conceitual de detecção de anomalias e antifraude.

Referências a **machine learning**, **tempo real**, **microserviços**, **resiliência**
ou **escalabilidade** neste projeto devem ser entendidas como temas de estudo e
experimentação, não como evidência de um sistema financeiro operando em produção.

## Limites

Fraude é um domínio de alto risco. Um sistema real exige dados representativos,
avaliação estatística, monitoramento de falsos positivos/negativos, governança,
segurança, requisitos regulatórios e validação contínua. Este repositório não
fornece essas garantias.

Os exemplos e regras presentes no código servem apenas para aprendizado.
